# UI Flow

## Inputs

- Language selector
- JSON editor (paste area)

## Actions

- Validate JSON
- Generate DOCX
- Generate PDF
- Download DOCX, PDF, or both
- Copy prompt with JSON examples

## UX Notes

- Show validation errors with a clear path to fix.
- Keep the UI simple and fast; no auth in v1.
- Provide a single-click copy for the AI prompt.
