# T02 - JSON Schema

## Story

As a user, I want a JSON format that mirrors the template sections
so I can paste structured data to generate my CV.

## Scope

- Define required and optional fields.
- Include list item shapes for repeated blocks.
- Define experience fields for responsibilities, keyResults, skills.
- Provide a sample JSON file.

## Acceptance Criteria

- Schema covers all DOCX sections.
- Optional fields do not break output when missing.
- Experience items require responsibilities, keyResults, skills arrays.
- Example JSON validates against the schema.
