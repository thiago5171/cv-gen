# T03 - DOCX Template Placeholders

## Story

As a developer, I need a DOCX template with placeholders so data can
be inserted automatically.

## Scope

- Replace all dynamic text with placeholders.
- Add repeat and conditional blocks.
- Add placeholders for responsibilities, keyResults, and skills in experience blocks.
- Keep layout identical to the original.

## Acceptance Criteria

- Template renders with a sample JSON.
- Experience sections render responsibilities, keyResults, and skills.
- Layout matches the original file visually.
