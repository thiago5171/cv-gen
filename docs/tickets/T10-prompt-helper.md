# T10 - Prompt Helper

## Story

As a user, I want a ready-to-copy AI prompt with JSON examples so I can
ask an AI to adapt my CV to a job description with fewer errors.

## Scope

- Provide a copyable prompt template.
- Include a full JSON example and a minimal JSON example.
- Reference the JSON schema so the AI output matches it.

## Acceptance Criteria

- One-click copy for the prompt.
- Prompt includes instructions for ATS-friendly output.
- Prompt warns the AI to keep the JSON structure unchanged.
