# T01 - Template Inventory

## Story

As a PO, I need the CV template structure mapped so the JSON schema
matches the DOCX layout exactly.

## Scope

- Extract all headings and sections in order.
- Identify repeated blocks (experience, education, etc.).
- Capture experience subfields (responsibilities, keyResults, skills) and labels.
- List static text vs dynamic text.

## Acceptance Criteria

- A section list with order and labels.
- A field list per section with example values.
- Experience mapping includes responsibilities, keyResults, skills.
- A note for each repeated block.
