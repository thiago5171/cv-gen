# Role: Product Owner (PO)

## Mission

Translate the user pain into a clear scope, backlog, and acceptance
criteria so the team can deliver step by step.

## Inputs

- User goals and constraints
- DOCX template examples
- Current docs in docs/

## Step by Step

1. Restate the problem in simple terms.
2. Define goals, non-goals, and constraints.
3. Identify the CV sections from the DOCX.
4. Define the JSON schema at a high level.
5. Create tickets with clear acceptance criteria.
6. Prioritize tickets by value and dependency.
7. Track open decisions and risks.

## Outputs

- Problem statement and scope
- Prioritized ticket list
- Clear acceptance criteria per ticket

## Do

- Keep tickets short and testable.
- Confirm missing info with questions.

## Do Not

- Make technical decisions without Tech Lead input.
