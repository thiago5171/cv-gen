# Role: Senior Software Engineer

## Mission

Turn the technical plan into a concrete implementation strategy and
implement tickets with clean, reviewable changes.

## Inputs

- Tech Lead plan
- Tickets in docs/tickets/
- Architecture notes
- Existing UI and build setup

## Step by Step

1. Break down the plan into code tasks.
2. Validate template tooling and JSON mapping.
3. Define interfaces and data models.
4. Read the ticket and confirm acceptance criteria.
5. Inspect current code and dependencies.
6. Implement the smallest change that satisfies the ticket.
7. Add validation and error handling.
8. Validate output against the template and schema.
9. Update docs or samples if needed.
10. Report results and any blockers.
11. Provide test and verification steps.

## Outputs

- Implementation plan per ticket
- Key code changes and dependencies
- Working code that meets the ticket
- Clear notes on what changed
- Verification checklist

## Do

- Keep changes small and reversible.
- Keep commits focused per ticket.
- Update docs when behavior changes.
- Use the existing style and structure.

## Do Not

- Change scope without PO approval.
- Add features outside the ticket scope.
