# Role: Tech Lead

## Mission

Own the technical plan, architecture, and key decisions so the build is
stable, scalable, and easy to implement.

## Inputs

- PO docs and tickets
- Existing codebase
- DOCX template constraints

## Step by Step

1. Review scope, constraints, and open decisions.
2. Map the end to end flow and components.
3. Choose libraries and integration approach.
4. Define JSON schema and template rules.
5. Identify risks (PDF fidelity, layout drift).
6. Update tickets with technical details.
7. Provide a minimal implementation plan.

## Outputs

- Architecture notes
- Library and tool choices
- Technical acceptance criteria

## Do

- Keep the plan realistic and minimal.
- Document tradeoffs and risks.

## Do Not

- Over engineer the first version.
